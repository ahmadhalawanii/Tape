Record once. Replay on every commit.

Tape patches the Anthropic SDK while a test runs. The first run records each request, response and tool result to a JSON tape. Every later run replays from it, and fails the moment the agent asks the model for something different.

test_refund_desk.pypytest
def test_declines_an_order_outside_the_window(client, tape):
    RefundDesk(client).handle(
        "I'd like a refund for my tent, order N1002.")

    tape.assert_called("check_policy", order_id="N1002")
    tape.assert_not_called("issue_refund")
    tape.assert_text_contains("store credit")

Specification

Records
Every messages.create call (sync, async, beta) and every function wrapped in @llmtape.tool, into plain JSON that diffs cleanly in git.
Replays
In milliseconds, at no cost, with no API key. Tools return their recorded output, so tests need no database.
Update mode
Replays while requests match and calls the API only from the first difference, so re-recording pays for the changed part of the run.
Diffs
Behaviour, not text: skipped and new tool calls, changed arguments, the final reply, tokens and cost. As text, markdown, JSON or an HTML page.
Asserts
assert_called, assert_called_before, assert_order, assert_cost_below and more, each failing with the whole tool trajectory.
Protects
API keys from Anthropic, OpenAI, AWS, GitHub, Stripe and Slack are redacted before a tape is written. A divergence can't be swallowed by an agent's except Exception.
In CI
Replay-only test runs, plus a behaviour diff of every changed tape in the pull request's job summary.
Limits
Anthropic SDK only for now. Streaming isn't recorded yet. The demo's tapes come from a scripted stand-in model so it runs without a key.
