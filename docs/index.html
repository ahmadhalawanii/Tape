Record once. Replay on every commit.

Tape patches the Anthropic SDK while your test runs. Nothing in your agent changes, and no client needs passing in.

Record

The first run calls Claude for real and saves each request, response and tool result to a JSON tape.

# first run, or LLMTAPE_MODE=record
pytest
# -> tests/tapes/test_refund/....json

Replay

Every later run answers from the tape. It's fast, free and the same every time, and tools don't need your database.

pytest --tape-mode=replay
# 0 API calls, no key needed

Diff

When a request no longer matches, the test fails at that call and Tape shows what the agent now does.

tape diff tests/tapes/x.json --git main
- check_policy(N1002)
+ issue_refund(N1002, 489)

Test what the agent does, not what it says.

Each assertion fails with the whole tool trajectory, so you see what happened instead of a bare False.

  • assert_called with a subset of arguments
  • assert_called_before("check_policy", "issue_refund")
  • assert_not_called, assert_order, assert_max_calls
  • assert_cost_below(0.01) from real token usage

Small library. Sharp edges handled.

Everything here is in the repo, with tests.

Update mode

Replays while requests match and calls the API only from the first difference, so re-recording pays for the part that changed.

Tools on tape

Wrap a function in @llmtape.tool and replay returns its recorded result, errors included.

Can't be swallowed

A divergence is a BaseException, so an agent's except Exception: fallback can't hide it.

Keys never saved

Anthropic, OpenAI, AWS, GitHub, Stripe and Slack keys are redacted before a tape is written.

Diffs you can read

Text, markdown, JSON or a single offline HTML page. See the demo report.

Limits, honestly

Anthropic SDK only for now, and streaming isn't recorded yet. The demo uses a scripted stand-in model so it runs without a key.
