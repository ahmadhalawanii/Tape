Record once. Replay on every commit.

Tape patches the Anthropic SDK while your tests run. Nothing in your agent changes.

SIDE 1

Record

The first run calls Claude for real and writes every request, response and tool result to a JSON tape.

# first run
pytest
# tests/tapes/test_refund/....json
SIDE 2

Replay

Every later run answers from the tape: fast, free and identical, with tool results replayed too.

pytest --tape-mode=replay
# 0 API calls, no key needed
SIDE 3

Diff

When a request stops matching, the test fails at that call and Tape shows what the agent does now.

tape diff x.json --git main
- check_policy(N1002)
+ issue_refund(N1002, 489)

Test what it does, not what it says.

Assertions read the tape, and a failure prints the agent's whole tool trajectory.

  • assert_called("check_policy", order_id="N1002")
  • assert_called_before("check_policy", "issue_refund")
  • assert_not_called("issue_refund")
  • assert_cost_below(0.01)
def test_declines_an_order_outside_the_window(client, tape):
    RefundDesk(client).handle(
        "I'd like a refund for my tent, order N1002.")

    tape.assert_called("check_policy", order_id="N1002")
    tape.assert_not_called("issue_refund")
    tape.assert_text_contains("store credit")
FAILED test_declines_an_order_outside_the_window

TapeDivergence: Run diverged at model call #0.
Request differs from the recording:
  system: "You are the returns desk for…"
       -> "You are the friendly returns desk…"

If the change is intended, re-record with
LLMTAPE_MODE=update.
